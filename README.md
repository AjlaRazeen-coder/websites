# Rose & Sky Cosmetics — Static Site

Simple static website demo for a cosmetics business. Color palette: white, pink, light blue.

How to open:

1. Open `index.html` in a browser (double-click or use "Open File").
2. Click categories on the main page to filter brands and see prices on `brands.html`.

Files added:

- `index.html` — Main page with categories and featured products.
- `brands.html` — Lists brands and prices; filtered by `?category=` query param.
- `styles.css` — Styles and color palette.
- `script.js` — Sample product data and rendering logic.
